# [마일스톤4-Day2] 레이블링 시스템 구축

## 📌 간단 개요
대전환/호재/악재 등 학습용 레이블 정의 및 자동/수동 레이블링 시스템 구축. 텔레그램 UI를 통한 수동 레이블링 지원.

## 🎯 목표
1. **레이블 체계 정립**: ML 학습에 필요한 7가지 레이블 타입 정의
2. **자동 레이블링**: 키워드 및 패턴 기반 자동 레이블링 시스템 구축
3. **수동 레이블링 UI**: 텔레그램 명령어를 통한 사용자 레이블링 지원
4. **레이블 통계**: 레이블 분포 및 품질 모니터링 기능 구현

## 🔧 개선사항

### 1. 레이블 체계 정의
**기존 문제**:
- 기사 분류 기준 없음
- ML 학습용 ground truth 데이터 부족
- 호재/악재 구분 수동 판단 필요

**개선 방향**:
- [ ] 7가지 레이블 타입 정의 및 문서화
  ```python
  LABELS = {
      "positive": "호재 (긍정적 뉴스)",
      "negative": "악재 (부정적 뉴스)",
      "game_changer": "대전환 (산업 판도 변화)",
      "regulatory": "규제 (법적, 정책적 변화)",
      "neutral": "중립 (사실 전달)",
      "breaking": "속보 (긴급 뉴스)",
      "exclusive": "단독 (독점 보도)"
  }
  ```
- [ ] 각 레이블의 판단 기준 명시
- [ ] 레이블 간 우선순위 정의 (복수 레이블 가능)

### 2. DB 스키마 추가
**기존 문제**:
- 레이블 정보 저장 테이블 없음
- 자동/수동 레이블 구분 불가
- 레이블 신뢰도 측정 불가

**개선 방향**:
- [ ] `article_labels` 테이블 생성
  ```sql
  CREATE TABLE article_labels (
      id INTEGER PRIMARY KEY,
      article_id TEXT NOT NULL,
      label_type TEXT NOT NULL,
      label_value TEXT NOT NULL,
      confidence REAL DEFAULT 1.0,
      labeled_by TEXT DEFAULT 'auto',  -- 'auto' or 'manual'
      labeled_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (article_id) REFERENCES articles(article_id)
  );
  ```
- [ ] 인덱스 생성 (article_id, label_value)
- [ ] 마이그레이션 스크립트 작성

### 3. 자동 레이블링 규칙
**기존 문제**:
- 모든 레이블링 수동 진행 필요
- 속도/단독 등 명확한 패턴도 수동 분류
- 대량 데이터 레이블링 비효율적

**개선 방향**:
- [ ] 키워드 기반 자동 레이블링
  - **positive**: "승인", "ETF", "상장", "채택", "도입", "상승"
  - **negative**: "규제", "금지", "제재", "하락", "폭락", "사기"
  - **game_changer**: "혁명", "대전환", "게임체인저", "패러다임"
  - **regulatory**: "법안", "규제", "정책", "금융당국"

- [ ] 제목 패턴 인식
  - `[속보]`, `[긴급]`, `[특보]` → `breaking`
  - `[단독]`, `[독점]` → `exclusive`

- [ ] 신뢰도(confidence) 계산
  - 키워드 1개 매칭: 0.3
  - 키워드 2개 매칭: 0.6
  - 키워드 3개 이상: 0.9

### 4. 수동 레이블링 UI
**기존 문제**:
- 사용자가 레이블 추가할 방법 없음
- 자동 레이블 검증 불가
- 레이블 조회 불편

**개선 방향**:
- [ ] 텔레그램 명령어 추가
  - `/label <article_id> <label>`: 기사에 레이블 추가
    - 예: `/label abc123 positive`
  - `/labels <article_id>`: 기사의 모든 레이블 조회
  - `/recent_unlabeled [N]`: 레이블 안 된 최근 기사 N개 보기 (기본 10개)
  - `/label_stats`: 레이블 통계 확인

- [ ] 인라인 키보드로 빠른 레이블링
  - 기사 전송 시 하단에 레이블 버튼 표시
  - 클릭으로 즉시 레이블 추가

### 5. 레이블 통계 및 품질 관리
**기존 문제**:
- 레이블 분포 파악 어려움
- 자동 레이블 정확도 측정 불가
- 품질 낮은 레이블 필터링 불가

**개선 방향**:
- [ ] 레이블 통계 기능
  - 레이블별 기사 수
  - 자동 vs 수동 레이블 비율
  - 평균 신뢰도
  - 복수 레이블 비율

- [ ] 품질 필터링
  - confidence < 0.5인 레이블 별도 표시
  - 수동 검증 필요 기사 목록

## ✨ 기대효과

### 1. ML 학습 데이터 준비
- **효과**: 레이블링된 데이터로 감성 분석, 분류 모델 학습 가능
- **지표**: 1,000개 기사 중 80% 이상 레이블링 완료

### 2. 자동화로 시간 절약
- **효과**: 자동 레이블링으로 수작업 70% 감소
- **지표**: 1,000개 기사 레이블링 시간 10시간 → 3시간

### 3. 레이블 품질 향상
- **효과**: 신뢰도 측정으로 품질 낮은 레이블 필터링
- **지표**: 평균 confidence 0.7 이상 유지

### 4. 사용자 피드백 반영
- **효과**: 텔레그램 UI로 사용자가 직접 레이블 추가 가능
- **지표**: 수동 레이블 비율 20% 이상 (품질 향상)
