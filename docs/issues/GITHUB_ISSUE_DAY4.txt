# [마일스톤4-Day4] 데이터 품질 검증 및 기초 통계

## 📌 간단 개요
ML 학습 전 데이터 품질 검증 및 기초 통계 분석. 품질 이슈 자동 탐지, 데이터 클리닝, 상세 리포트 생성.

## 🎯 목표
1. **데이터 품질 검증**: Null 값, 중복, 이상치 자동 탐지 및 리포트
2. **기초 통계 분석**: 섹터별, 도메인별, 시간별 분포 분석 및 시각화
3. **키워드 빈도 분석**: 트렌딩 키워드 및 섹터별 주요 키워드 추출
4. **데이터 클리닝**: 품질 이슈 자동 수정 및 불량 데이터 제거

## 🔧 개선사항

### 1. 데이터 품질 체크
**기존 문제**:
- 데이터 품질 수동 확인 필요
- Null 값, 중복, 이상치 탐지 어려움
- 품질 이슈 발견 늦음 (ML 학습 중 오류 발생)

**개선 방향**:
- [ ] **Null 값 검사**
  - 필드별 누락 비율 계산 (title, summary, content, published_at)
  - 임계값 설정: content null > 30% → 경고
  - Null 패턴 분석 (특정 언론사, 시간대)

- [ ] **중복 기사 탐지**
  - link 기준 완전 중복
  - 제목 유사도 (edit distance < 5)
  - 중복 기사 목록 출력

- [ ] **이상치 탐지**
  - content_length 너무 짧음 (< 100자)
  - content_length 너무 김 (> 100,000자)
  - published_at 미래 날짜
  - published_at > fetched_at

- [ ] **날짜 오류 검사**
  - 타임존 불일치
  - 날짜 포맷 오류
  - 날짜 순서 이상 (published > fetched)

### 2. 기초 통계 리포트
**기존 문제**:
- 데이터 분포 파악 어려움
- 섹터/도메인별 불균형 모름
- 시간대별 수집 패턴 불명확

**개선 방향**:
- [ ] **전체 통계**
  - 전체 기사 수
  - 레이블링 완료율
  - 피드백 참여율
  - 평균 content_length

- [ ] **섹터별 분포**
  - 5개 주요 섹터별 기사 수
  - 섹터별 비율 (파이차트 데이터)
  - 불균형 감지 (한 섹터 > 50%)

- [ ] **도메인(언론사)별 분포**
  - Top 10 언론사
  - 언론사별 기사 수 및 비율
  - 단일 언론사 독점 여부

- [ ] **시간대별 수집량**
  - 일별 수집량 (최근 30일)
  - 주별 수집량
  - 시간대별 분포 (00시~23시)
  - 수집 트렌드 (증가/감소)

- [ ] **레이블 분포**
  - 레이블별 기사 수
  - 자동 vs 수동 레이블 비율
  - 평균 confidence
  - 복수 레이블 비율

- [ ] **피드백 통계**
  - 평균 likes/dislikes
  - 피드백 있는 기사 비율
  - 피드백 분포 (0개, 1-2개, 3-5개, 6개 이상)

### 3. 키워드 빈도 분석
**기존 문제**:
- 키워드 트렌드 파악 어려움
- 섹터별 주요 키워드 불명확
- 시간별 키워드 변화 모름

**개선 방향**:
- [ ] **전체 키워드 Top 50**
  - keyword_extracted 필드에서 추출
  - 빈도순 정렬
  - 워드클라우드 데이터 생성 (선택)

- [ ] **섹터별 주요 키워드**
  - 각 섹터별 Top 10
  - 섹터 특징적 키워드 추출

- [ ] **시간별 트렌딩 키워드**
  - 주별 Top 키워드 변화
  - 급상승 키워드 탐지
  - 트렌드 분석

### 4. 데이터 클리닝
**기존 문제**:
- 품질 이슈 수동 수정 필요
- 불량 데이터 방치
- ML 학습 시 노이즈 발생

**개선 방향**:
- [ ] **자동 클리닝 로직**
  - 중복 제거 (link 기준, 최신 것만 유지)
  - 짧은 기사 제외 (content_length < 100)
  - 언어 필터링 (한국어만 유지)
  - 날짜 오류 수정/제거

- [ ] **Dry-run 모드**
  - 클리닝 미리보기 (실제 적용 전)
  - 제거/수정될 기사 목록 출력
  - 사용자 확인 후 적용

- [ ] **클리닝 로그**
  - 제거된 기사 수
  - 수정된 기사 수
  - 클리닝 전후 통계 비교

### 5. 리포트 생성
**기존 문제**:
- 통계 정보 산발적
- 일관된 리포트 형식 없음
- 이력 관리 어려움

**개선 방향**:
- [ ] **Markdown 리포트**
  - 일관된 형식
  - 섹션별 구분 (품질, 통계, 키워드)
  - 테이블 및 차트 데이터 포함
  - 파일명: `data/csv/quality_report_YYYYMMDD.md`

- [ ] **JSON 통계**
  - 프로그래밍 방식 접근 가능
  - 시계열 분석용
  - 파일명: `data/csv/stats_YYYYMMDD.json`

## ✨ 기대효과

### 1. 데이터 품질 보장
- **효과**: ML 학습 시 오류 최소화, 모델 성능 향상
- **지표**: 품질 이슈 < 5%, content null < 10%

### 2. 데이터 이해도 향상
- **효과**: 데이터 특성 파악으로 적절한 ML 기법 선택 가능
- **지표**: 5가지 이상 통계 지표 제공

### 3. 트렌드 파악
- **효과**: 키워드 분석으로 뉴스 트렌드 이해, 섹터별 특징 파악
- **지표**: 섹터별 Top 10 키워드 추출 완료

### 4. 자동화된 클리닝
- **효과**: 수동 클리닝 시간 90% 절감, 데이터 일관성 향상
- **지표**: 클리닝 시간 < 1분 (1,000개 기사 기준)
