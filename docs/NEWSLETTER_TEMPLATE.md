## 예시 1: IT 섹터 + AI·반도체 테마

```markdown
# [뉴스-001] 삼성전자, 3나노 GAA 공정 기반 AI 반도체 양산 시작

## 📊 분류 (Classification)

### 산업 (Sector)
- [x] IT (IT)

### 테마 (Themes)
- [x] 반도체 (SEMICONDUCTOR)
- [x] AI (AI)

### 사건 (Events)
- 없음

---

## 📰 뉴스 내용

### 제목
삼성전자, 세계 최초 3나노 GAA 공정 AI 반도체 양산 돌입

### 요약
삼성전자가 세계 최초로 3나노 GAA(Gate-All-Around) 공정 기술을 적용한 AI 전용 반도체 양산을 시작했다. 이번 반도체는 기존 5나노 공정 대비 성능 30% 향상, 전력 소모 50% 감소를 달성했다. 엔비디아, 구글 등 글로벌 빅테크 기업들이 주요 고객이 될 것으로 예상된다.

### 출처
- **언론사**: 전자신문
- **게시일**: 2025-01-15
- **링크**: https://example.com/news/001

---

## 🔍 키워드
- 삼성전자, 3나노, GAA, AI 반도체, 양산, 엔비디아

---

## 💡 인사이트
삼성전자가 TSMC와의 파운드리 경쟁에서 기술적 우위를 확보하는 중요한 전환점이다. AI 반도체 수요 급증에 발맞춰 고성능 반도체 생산 능력을 입증함으로써 글로벌 시장 점유율 확대가 기대된다.
```

## 분류 선택 가이드

### Sector (산업) 선택 기준

| Sector | 주요 키워드 | 예시 |
|--------|------------|------|
| **ENERGY** | 석유, 가스, 신재생에너지 | "LG에너지솔루션 배터리 공장" |
| **MATERIALS** | 철강, 화학, 소재 | "포스코 양극재 생산" |
| **INDUSTRIALS** | 조선, 건설, 기계, 방산 | "HD현대 조선소 수주" |
| **IT** | 반도체, 소프트웨어, 하드웨어 | "삼성전자 AI 반도체" |
| **COMMUNICATION** | 통신, 미디어, OTT | "넷플릭스 한국 콘텐츠" |
| **FINANCIALS** | 은행, 증권, 보험 | "암호화폐 ETF 승인" |
| **HEALTHCARE** | 제약, 바이오, 병원 | "신약 임상시험 승인" |
| **CONSUMER** | 유통, 자동차, 식음료 | "현대차 전기차 수출" |
| **UTILITIES** | 전력, 가스, 수도 | "한전 전력 요금 인상" |
| **REAL_ESTATE** | 부동산, 건설, 리츠 | "주택 공급 확대 정책" |
| **PUBLIC_POLICY** | 정부 정책, 규제, 법안 | "로봇 산업 규제 샌드박스" |

### Theme (테마) 선택 기준

**여러 개 선택 가능** (기사 내용과 관련된 모든 테마 체크)

- **SEMICONDUCTOR**: 반도체 제조, 설계, 장비
- **BATTERY**: 2차전지, ESS, 배터리 소재
- **AI**: 인공지능, 머신러닝, LLM
- **AUTONOMOUS**: 자율주행, 무인선박, 드론
- **ROBOTICS**: 산업로봇, 서비스로봇
- **GREEN**: ESG, 탄소중립, 재생에너지
- **LNG**: 액화천연가스, 가스선
- **CONTENT**: K-pop, OTT, 게임, 웹툰
- **PLATFORM**: 이커머스, 배달앱, 공유경제
- **DEFENSE**: 방위산업, 무기 수출

### Event (사건) 선택 기준

**특정 시점의 개별 이슈**에만 체크 (대부분의 뉴스는 해당 없음)

- **HMM_ACQUISITION**: HMM 인수전 관련 모든 기사
- **HD_HYUNDAI_AUTONOMOUS**: HD현대의 자율운항 사업 협력 관련
- **POSCO_RESTRUCTURE**: 포스코 그룹 구조조정 관련

## 템플릿 사용법

1. 새로운 뉴스를 작성할 때 이 템플릿을 복사합니다.
2. **산업(Sector)**에서 **1개만** 선택합니다.
3. **테마(Themes)**에서 **해당되는 모든 항목**을 선택합니다.
4. **사건(Events)**은 특정 이슈에 해당되는 경우만 선택합니다.
5. 뉴스 내용을 작성하고 저장합니다.
